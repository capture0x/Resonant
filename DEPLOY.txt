# Resonant OSINT System - Production Deployment Guide

## 1. System Requirements
- Python 3.11+
- PostgreSQL 13+
- 16GB+ RAM recommended for concurrent OSINT operations
- 4+ CPU cores recommended
- 50GB+ storage space
- Nginx
- Supervisor or systemd

## 2. Installation Steps

### 2.1. System Setup
```bash
# Update system and install dependencies
sudo apt update && sudo apt upgrade -y
sudo apt install python3-pip python3-venv postgresql postgresql-contrib nginx -y

# Create a dedicated user
sudo useradd -m -s /bin/bash Resonant
sudo su - Resonant
```

### 2.2. Application Setup
```bash
# Clone repository
git clone https://github.com/yourusername/Resonant.git
cd Resonant

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
pip install gunicorn psycopg2-binary
```

### 2.3. Database Setup
```bash
# Create PostgreSQL database
sudo -u postgres psql
postgres=# CREATE DATABASE Resonant;
postgres=# CREATE USER Resonant WITH PASSWORD 'your_secure_password';
postgres=# GRANT ALL PRIVILEGES ON DATABASE Resonant TO Resonant;
postgres=# \q
```

### 2.4. Environment Configuration
Create a .env file in the project root:
```
FLASK_ENV=production
FLASK_APP=app.py
SECRET_KEY=your_secure_secret_key
DATABASE_URL=postgresql://Resonant:your_secure_password@localhost/Resonant
```

### 2.5. Initialize Database
```bash
# Create database tables
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

### 2.6. Gunicorn Configuration
Create /etc/supervisor/conf.d/Resonant.conf:
```ini
[program:Resonant]
directory=/home/Resonant/Resonant
command=/home/Resonant/Resonant/venv/bin/gunicorn -w 4 -b 127.0.0.1:8000 "app:create_app('production')"
user=Resonant
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
stderr_logfile=/var/log/Resonant/Resonant.err.log
stdout_logfile=/var/log/Resonant/Resonant.out.log
```

### 2.7. Nginx Configuration
Create /etc/nginx/sites-available/Resonant:
```nginx
server {
    listen 80;
    server_name your_domain.com;

    access_log /var/log/nginx/Resonant.access.log;
    error_log /var/log/nginx/Resonant.error.log;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        
        # Extended timeouts for long-running requests
        proxy_connect_timeout 300s;
        proxy_send_timeout 900s;
        proxy_read_timeout 900s;
        
        # WebSocket support
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 2.8. Start Services
```bash
# Create log directories
sudo mkdir /var/log/Resonant
sudo chown Resonant:Resonant /var/log/Resonant

# Start/reload services
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start Resonant
sudo nginx -t && sudo systemctl restart nginx
```

## 3. Maintenance

### 3.1. Backup Setup
Create /home/Resonant/backup.sh:
```bash
#!/bin/bash
BACKUP_DIR="/home/Resonant/backups"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

# Database backup
pg_dump Resonant > $BACKUP_DIR/Resonant$DATE.sql

# Compress backup
gzip $BACKUP_DIR/Resonant$DATE.sql

# Keep only last 7 days of backups
find $BACKUP_DIR -type f -mtime +7 -delete
```

Add to crontab:
```bash
0 3 * * * /home/Resonant/backup.sh
```

### 3.2. Updating Application
```bash
cd /home/Resonant/Resonant
source venv/bin/activate
git pull
pip install -r requirements.txt
flask db upgrade
sudo supervisorctl restart Resonant
```

## 4. Troubleshooting

### 4.1. Log Locations
- Application logs: /var/log/Resonant/
- Nginx logs: /var/log/nginx/
- Supervisor logs: /var/log/supervisor/
- System logs: /var/log/syslog

### 4.2. Common Issues
1. Database connection errors:
   - Check PostgreSQL service status
   - Verify DATABASE_URL in .env
   - Check PostgreSQL logs

2. 502 Bad Gateway:
   - Check Gunicorn status
   - Verify Nginx configuration
   - Check application logs

## 5. Performance Tuning

### 5.1. PostgreSQL
Edit /etc/postgresql/12/main/postgresql.conf:
```ini
max_connections = 100
shared_buffers = 2GB
effective_cache_size = 6GB
work_mem = 20MB
maintenance_work_mem = 512MB
```

### 5.2. Gunicorn
Adjust workers based on CPU cores:
workers = (2 * num_cores) + 1

### 5.3. Nginx
Edit /etc/nginx/nginx.conf:
```nginx
worker_processes auto;
worker_connections 1024;
keepalive_timeout 65;
client_max_body_size 10M;
```

## 6. Monitoring and Maintenance

### 6.1. System Monitoring
Monitor system resources:
```bash
sudo apt install htop iotop -y
```

### 6.2. Application Monitoring
Set up logging:
```bash
mkdir logs
touch logs/Resonant.log
chmod 666 logs/Resonant.log
```

### 6.3. Memory Management
- No memory limits set on workers to allow full system RAM usage
- Monitor memory usage with `htop`
- Consider using `systemd` service with automatic restart on OOM

### 6.4. Systemd Service
Create `/etc/systemd/system/Resonant.service`:
```ini
[Unit]
Description=Resonant OSINT System
After=network.target

[Service]
User=Resonant
WorkingDirectory=/path/to/Resonant
Environment="PATH=/path/to/Resonant/venv/bin"
ExecStart=/path/to/Resonant/venv/bin/gunicorn -w 4 -b 127.0.0.1:8000 --timeout 900 --graceful-timeout 300 --keep-alive 120 --worker-class gthread --threads 4 "app:create_app('production')"
Restart=always
RestartSec=10

# No memory limit
# LimitMEMLOCK=infinity
# LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

Start service:
```bash
sudo systemctl start Resonant
sudo systemctl enable Resonant
```

## 7. Important Note for Production
This application performs intensive OSINT operations that can:
- Take 5-10+ minutes to complete
- Use significant memory (up to available system RAM)
- Make multiple concurrent API calls

Configure Gunicorn accordingly:
```bash
gunicorn -w 4 -b 127.0.0.1:8000 \
  --timeout 900 \           # 15 minute timeout
  --graceful-timeout 300 \  # 5 minute graceful shutdown
  --keep-alive 120 \        # Keep-alive connections
  --worker-class gthread \  # Thread-based workers for async operations
  --threads 4 \            # 4 threads per worker
  --max-requests 100 \     # Restart workers occasionally to prevent memory leaks
  --max-requests-jitter 10 \ 
  "app:create_app('production')"
```

# Troubleshooting
- Check logs: `tail -f logs/Resonant.log`
- Monitor workers: `ps aux | grep gunicorn`
- Check memory: `free -h`
- Database connections: `sudo -u postgres psql -d Resonant -c 'SELECT * FROM pg_stat_activity;'`

Remember: This application is designed to use significant system resources for OSINT operations. Ensure your VPS has adequate RAM and CPU resources.
